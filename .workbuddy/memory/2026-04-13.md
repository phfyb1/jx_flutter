# 2026-04-13 工作日志

## ModBusServer 多数据类型升级

### 新增支持的数据类型（ControllerUtils）
- `int16BE` / `int16LE`：有符号 2 字节，大端/小端
- `uint16BE` / `uint16LE`：无符号 2 字节，大端/小端
- `int32DCBA` / `int32BADC` / `int32CDAB` / `int32ABCD`：有符号 4 字节
- `uint32DCBA` / `uint32BADC` / `uint32CDAB` / `uint32ABCD`：无符号 4 字节
- `float64DCBA` / `float64BADC` / `float64CDAB` / `float64ABCD`：双精度 8 字节

### Controller 重构（ModBusServerController）
- 引入 `DataType` 枚举（id/label/byteSize）和 `ByteOrder` 枚举
- 全局 `dataType` + `byteOrder` 选择，切换时自动重解析
- 2 字节类型（Int16/UInt16）字节序选项自动收敛为 Big/Little 两种
- `_rawDataBytes` 缓存原始数据帧，支撑重解析

### 字节序修正
- 旧代码：函数名和实际行为完全错位
- 新代码：bigEndianToFloat = DCBA（标准大端），littleEndianToFloat = ABCD（标准小端）
- 2 字节：Big = 大端（高位在前），Little = 小端（低位在前）
- Float64：用 Float64List.view 实现（ByteData 无 setUint64）

## 新增功能：MQTT 日志解析（2026-04-13 下午）

### 功能说明
- 输入：粘贴 `{ ts, values[] }` 格式的 MQTT JSON 日志
- 解析后显示 values 条数、外层 ts 时间戳、时间范围
- 查询：输入 code 精准查询，返回所有匹配记录
- 每条记录展示：序号、code（高亮）、status（在线/离线）、value、type、timestamp（格式化）、sn
- 长按复制单条完整信息
